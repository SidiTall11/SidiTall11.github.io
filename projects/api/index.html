POST /auth/register Créer un compte utilisateur
Informations
Tester

Crée un nouveau compte utilisateur. Retourne un access token et un refresh token JWT à la création.

Corps de la requête

ChampTypeRequisDescription
usernamestringOuiNom d'utilisateur unique (3-30 chars)
emailstringOuiAdresse email valide
passwordstringOuiMinimum 8 caractères
first_namestringNonPrénom
Exemple JSON
{
  "username": "sidi_tall",
  "email": "sidi@example.com",
  "password": "MonMotDePasse123!",
  "first_name": "Sidi"
}
201Utilisateur créé — retourne access_token et refresh_token
400Données invalides ou email/username déjà utilisé
422Erreur de validation (format email, mot de passe trop court...)

Corps (JSON)
POST /auth/login Connexion utilisateur
Informations
Tester

Authentifie un utilisateur et retourne une paire de tokens JWT (access + refresh).

Requête
{
  "username": "sidi_tall",
  "password": "MonMotDePasse123!"
}
Réponse 200
{
  "access":  "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "refresh": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "user": {
    "id": 1,
    "username": "sidi_tall",
    "email": "sidi@example.com",
    "role": "user"
  }
}
200Succès — retourne access + refresh tokens
401Identifiants incorrects
Tester l'endpoint
Corps (JSON)
POST /auth/refresh Renouveler le token
Informations
Tester

Génère un nouveau access token à partir d'un refresh token valide. L'access token expire après 15 minutes.

Requête
{ "refresh": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..." }
200Nouveau access token généré
401Refresh token expiré ou invalide
Tester
Corps
GET /users Liste des utilisateurs
Informations
Tester

Retourne la liste paginée des utilisateurs. Requiert le rôle admin.

Paramètres de requête

ParamètreTypeRequisDescription
pageintegerNonNuméro de page (défaut: 1)
limitintegerNonRésultats par page, max 100 (défaut: 20)
searchstringNonRecherche par username ou email
Réponse 200
{
  "count": 42,
  "next": "https://api.novaapp.dev/v1/users?page=2",
  "previous": null,
  "results": [
    { "id":1, "username":"sidi_tall", "email":"sidi@example.com", "role":"admin", "created_at":"2025-01-15T10:30:00Z" }
  ]
}
200Liste paginée des utilisateurs
401Token manquant ou invalide
403Accès refusé — rôle admin requis
Tester
Authorization Token
